# Chicken Systems Translator Pro — manual (referinta)

Aici urca **`translator.chm`** (user guide-ul de la Chicken Systems
Translator Pro v2.9.0), ca sa pot examina exact pasii de conversie
DirectWave (.dwp) -> EXS24 (.exs) pentru versiunea ta.

Dupa ce analizez manualul, scriu un ghid pe pasi numerotati in:
`docs/sampler/TRANSLATOR-DWP-TO-EXS.md`.

## Cum urci fisierul (din browser)

1. Intri pe ramura noastra, in acest folder:
   https://github.com/DarrSasa/Ample_Guitar_Chord-Settings_Helper/tree/arena/01a00f12-ample-guitar-chord-settings-he/docs/sampler/translator
2. **Add file -> Upload files**.
3. Trage `translator.chm` si apasa **Commit changes** (direct pe ramura).

## Sau (daca .chm-ul e mare)

Zi-mi si-ti dau alta varianta (ex. il pui intr-un zip sau il trimiti altfel).
