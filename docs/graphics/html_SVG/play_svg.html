Note despre efectele fizice folosite

Fiecare buton "On" foloseste:
  • Halo exterior - feGaussianBlur mare pe forma butonului cu culoarea LED-ului
  • LED radial - radialGradient cu atenuare exponentiala (legea inversului patratului)
  • Corp mai luminos - gradiente cu tonuri lift-uite (LED-ul reflecta si pe corpul butonului)
  • Bevel top - highlight semi-transparent care simuleaza reflexia stratului de deasupra
  • Semn iluminat - 2 straturi cu mix-blend-mode: screen pentru a-i aduce lumina LED-ului
  • Border negru - pastreaza definitia formei chiar cu halo puternic
