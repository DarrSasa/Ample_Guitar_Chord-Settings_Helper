# Mostre pentru butoane realiste

Aici pui mostrele pe care le gasesti pe web sau le creezi in Photoshop pentru
fiecare buton. Denumire conventie:

## Obligatorii (2)

- `fundal-buton-<nume>.jpg/png` - corpul butonului (stare Off, fara LED)
- `semn-<nume>.jpg/png` - pictograma (X, triunghi, patrat etc.)

## Optionale (adauga pentru realism suplimentar)

- `led-<nume>.jpg/png` - LED-ul aprins (culoare + halo intern)
- `halo-<nume>.jpg/png` - aureola luminoasa exterioara (poate fi generata automat)
- `reflexie-<nume>.jpg/png` - highlight de sticla pe top
- `textura-<nume>.jpg/png` - textura de material (metal, plastic, cauciuc)
- `inspiratie-<nume>.jpg/png` - captura de la un buton dintr-un plugin/DAW/hardware
  care iti place, ca ghid vizual

## Unde le pui

Toate fisierele in acest folder: `docs/graphics/mostre/`

## Nume-butoane in aplicatie

- delete, play, pause, stop, drag, save, snap, undo, redo, start,
  scroll-on-off, ch-on-off, settings

## Ce sa cauti pe web

- **Fundal buton**: "button base texture", "synth knob background",
  "VST plugin button empty", "guitar pedal button". Site-uri: pixabay,
  unsplash, pngimg.
- **Semn/pictograma**: iconify.design, flaticon.com, thenounproject.com
- **LED aprins**: "LED button glow", "light indicator" - sau il generez eu procedural.
- **Inspiratie**: capturi cu Snipping Tool din FL Studio, Ableton, Serum,
  FabFilter, Waves. Salveaza ca `inspiratie-<nume>.jpg`.
