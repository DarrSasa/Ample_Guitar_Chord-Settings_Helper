Suomalaisista 5-kielisen banjon soittajista tunnetuimpia ovat folk-aikakaudella esiin nousseet edesmenneet[Pertsa Reponen](https://fi.wikipedia.org/wiki/Pertti_Reponen "Pertti Reponen")([Hootenanny Trio](https://fi.wikipedia.org/wiki/Hootenanny_Trio "Hootenanny Trio"),[Finntrio](https://fi.wikipedia.org/wiki/Finn_Trio "Finn Trio")),[Hannu Karlsson](https://fi.wikipedia.org/wiki/Hannu_Karlsson?action=edit&redlink=1 "Hannu Karlsson \(sivua ei ole\)")([Alan Miehet](https://fi.wikipedia.org/wiki/Alan_Miehet "Alan Miehet"),[Pihasoittajat](https://fi.wikipedia.org/wiki/Pihasoittajat "Pihasoittajat")) ja[Petri Hohenthal](https://fi.wikipedia.org/wiki/Petri_Hohenthal "Petri Hohenthal")([Cumulus](https://fi.wikipedia.org/wiki/Cumulus_\(yhtye\) "Cumulus \(yhtye\)"), Alan Miehet) sekä edelleen vaikuttava[Vesa Nuotio](https://fi.wikipedia.org/wiki/Vesa_Nuotio "Vesa Nuotio")(Finntrio, Alan Miehet). 70-luvun banjisteista tunnetuimpia ovat[Kari Reiman](https://fi.wikipedia.org/wiki/Kari_Reiman?action=edit&redlink=1 "Kari Reiman \(sivua ei ole\)")([Mayflower](https://fi.wikipedia.org/wiki/Mayflower_\(yhtye\) "Mayflower \(yhtye\)"),[Bottom String Band](https://fi.wikipedia.org/wiki/Bottom_String_Band?action=edit&redlink=1 "Bottom String Band \(sivua ei ole\)"),[Korkkijalka](https://fi.wikipedia.org/wiki/Korkkijalka "Korkkijalka")) ja[Seppo Sillanpää](https://fi.wikipedia.org/wiki/Seppo_Sillanp%C3%A4%C3%A4 "Seppo Sillanpää")([Vanha Isäntä](https://fi.wikipedia.org/wiki/Vanha_Is%C3%A4nt%C3%A4 "Vanha Isäntä"), Bottom String Band).
