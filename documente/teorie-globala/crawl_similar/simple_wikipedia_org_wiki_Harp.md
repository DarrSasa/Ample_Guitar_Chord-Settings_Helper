Harps have[strings](https://simple.wikipedia.org/wiki/String_\(physics\) "String \(physics\)")that are tied to the[frame](https://simple.wikipedia.org/wiki/Framework "Framework"), which is usually a[triangle](https://simple.wikipedia.org/wiki/Triangle "Triangle")made of[wood](https://simple.wikipedia.org/wiki/Wood "Wood"). Each string is tight, and the frame must be strong so that the many tight strings do not break it. The side of the triangle that leans on the player's body is called the "sound box".
The top side of the triangle has a lot of[pegs](https://simple.wiktionary.org/wiki/pegs "wikt:pegs")in it. There is one peg for each string on the harp. The top of each string is tied to one peg, and twisted around the peg. The player turns the peg to make the string more tight or less tight. This is how the player makes each string make the right note. The bottom of each string is tied to the sound box.
The last side of the triangle is called the pillar. Many of the oldest harps did not have them. If the strings were too tight, they would break the harp. Adding a pillar to a harp frame makes the frame very strong, so that the strings will not break it.
Harp players pluck the strings with their[fingers](https://simple.wikipedia.org/wiki/Finger "Finger"), similar to a[guitar](https://simple.wikipedia.org/wiki/Guitar "Guitar"). This makes the strings move so that the strings make[sounds](https://simple.wikipedia.org/wiki/Sound "Sound"). Each string sound is a different musical[note](https://simple.wikipedia.org/wiki/Note_\(music\) "Note \(music\)"). Harp players play music by plucking the strings in the right order and at the right time. More than one string can be plucked at the same time to make a[chord](https://simple.wikipedia.org/wiki/Chord "Chord"), or they can be played quickly, one after another, to make an[arpeggio](https://simple.wikipedia.org/wiki/Arpeggio "Arpeggio"). When the harp player wants a note to stop, they touch that string softly, so that it stops moving.
The**folk harp** is the older kind of harp, the oldest dating back to 3000 BC in[Ancient Egypt](https://simple.wikipedia.org/wiki/Ancient_Egypt "Ancient Egypt"). In these harps, each string can only make one note at a time. They are usually tuned so that playing each string in order sounds like playing all the white notes on a[piano](https://simple.wikipedia.org/wiki/Piano "Piano")in order. This is called a[diatonic scale](https://simple.wikipedia.org/wiki/Diatonic_scale "Diatonic scale"). In some places, they are tuned so that playing each string in order sounds like playing all the black notes on a piano in order. This is called a[pentatonic scale](https://simple.wikipedia.org/wiki/Pentatonic_scale "Pentatonic scale").
A**cross-strung harp** is a pedal harp that is[chromatic](https://simple.wikipedia.org/wiki/Chromatic "Chromatic")and consists of two rows of strings. They cross near to the middle of the string without touching. The strings are in the order of the piano keys (7 plus 5) or in the order of the[6-plus-6](https://simple.wikipedia.org/wiki/6-plus-6-instruments "6-plus-6-instruments")system.
* An**[Aeolian harp](https://simple.wikipedia.org/wiki/Aeolian_harp?action=edit&redlink=1 "Aeolian harp \(not yet started\)")** is just a box with tuned strings on it, and is not played by a human. It is just placed outdoors where the[wind](https://simple.wikipedia.org/wiki/Wind "Wind")blows. The wind makes the strings move so that they make notes.
